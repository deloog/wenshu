# 文枢数据清单（G0）

> 状态：G0 已批准（2026-07-20）。Alpha 默认本地优先、无自动同步、无强制账号。任何新增数据收集必须先更新本清单，再实现。

| 数据类别 | 示例 | 真源/派生 | 默认位置 | 是否可传模型 | 保留与删除 |
|---|---|---|---|---|---|
| 项目元数据 | 项目 ID、标题、创建/修改时间、schema 版本 | 真源 | 用户本地项目 | 否，除非任务必要 | 随项目导出/删除 |
| 类型化文档对象 | 章节、段落、表格、图片引用、稳定节点 ID | 真源 | 用户本地项目 | 仅用户明确触发的相关最小片段 | 随项目；可完整导出/删除 |
| 原始资料与附件 | Markdown、docx、图片、表格、参考文件 | 真源/外部来源 | 用户授权的本地项目目录 | 默认不传；逐任务明确选择 | 用户控制；删除前确认 |
| 模板与规则 | 模板 JSON/DSL、版本、布局 token、validator | 真源 | 应用内置或用户项目/模板库 | 通常不需要 | 可导出；第三方来源留证 |
| 用户偏好 | 模板选择、字体/样式偏好、不可改项 | 真源 | 本地配置/项目 | 仅任务必要部分 | 可重置/导出 |
| 编辑器事务 | 键入、粘贴、移动节点、undo/redo | 短期状态 | 编辑器历史 | 否 | 按编辑器历史策略裁剪 |
| 合并记录 | CRDT updates 等 | 机器状态 | 项目包；同步阶段另定 | 否 | 随项目；可压缩/重建策略另定 |
| 语义审计事件 | AI 重写、接受修改、引用、批准版本 | 真源 | 项目审计记录 | 不主动传；需要上下文时最小化 | 随项目导出/删除 |
| 出处信息 | 来源 ID、材料引用、内容哈希、受影响节点 | 真源 | 项目审计/引用层 | 只传任务必要引用内容 | 随项目；缺失来源要可检测 |
| 版本/快照 | 正式版本、检查点、导出记录 | 真源 | 本地项目 | 默认否 | 用户可清理，正式版本删除需确认 |
| 导出成品 | PDF、docx、Markdown、完整知识包 | 用户产物 | 用户选择路径 | 否 | 由用户文件系统控制 |
| 缓存 | 渲染中间物、缩略图、模型临时响应 | 派生 | 本地缓存 | 已产生的数据不二次外传 | 可随时清理；不作为唯一来源 |
| 搜索/向量索引 | 全文索引、embedding | 派生、可重建 | 本地优先 | embedding 生成是否外传须单独授权 | 可删除、可重建、不参与真源同步 |
| 模型凭证 | API key、endpoint、模型配置 | 高敏感配置 | OS 安全存储 | 仅发往所选服务认证端点 | 用户可撤销/清除；绝不进项目包 |
| 模型调用记录 | provider、模型版本、参数、成本、时间 | 审计元数据 | 本地审计/诊断 | 不需要 | 内容默认不完整记录；按隐私策略清理 |
| 诊断日志 | 错误码、版本、性能、关联 ID | 派生 | 本地；上传须另行同意 | 否 | 默认短期；不得包含正文/密钥/PII |
| 遥测/分析 | 功能事件、崩溃信息 | Alpha 默认不启用 | 无 | 否 | 后续启用前需清单、同意和隐私政策 |

## 数据分级

- **S0 公开**：公开模板元数据、公开文档。
- **S1 内部**：非敏感配置、性能统计、无内容诊断。
- **S2 用户私有**：项目正文、附件、偏好、审计与出处。
- **S3 高敏感**：凭证、可能含个人/商业秘密的资料、身份与支付信息。

S2/S3 默认不得出设备。用户触发模型任务时，只发送完成该任务必要的最小上下文，并在界面明确 provider、材料范围和可能成本。S3 凭证只能进入 OS 安全存储，不写日志、项目包、剪贴板历史或崩溃报告。

## 生命周期原则

1. 完整知识包是可迁移真源；导出后应能在干净环境重新导入。
2. 删除项目必须说明会删除哪些本地真源、哪些外部导出不会被删除，以及是否可恢复。
3. 缓存和索引有独立清理入口；清理不得损坏项目。
4. Alpha 手工备份/知识包导出必须验证恢复，不把“导出成功”当成可恢复。
5. 后续同步、账号、遥测、付费和云模型托管均须先更新本清单、威胁模型和隐私承诺，并重新过相应闸门。
