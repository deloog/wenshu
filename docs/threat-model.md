# 文枢轻量威胁模型（G0）

> 状态：G0 已批准（2026-07-20）。范围覆盖本地优先 Alpha、模型调用、导入导出、模板 DSL、桌面壳与鸿蒙薄壳；同步和模板市场上线前必须扩展。

## 1. 需要保护的资产

- 用户项目正文、附件、出处、历史版本和审计记录
- 模型 API 凭证及服务配置
- 用户文件系统和已授权目录
- 模板/规则引擎与导出管线
- 项目包、备份和正式交付成品
- 应用更新、签名和依赖供应链

## 2. 信任边界

```text
不可信：用户/外部文件、网页内容、第三方模板、模型输出、插件/依赖、外部链接
                              ↓ schema + 权限 + 大小/类型 + 内容检查
受控核心：类型化文档、事务、规则引擎、审计、host 能力协议
                              ↓ 最小权限
高权限：本地文件系统、打印/导出、OS 安全存储、平台能力、外部模型 API
```

## 3. 主要威胁与控制

| 威胁 | 可能后果 | G0 规定的控制 |
|---|---|---|
| 恶意/畸形 docx、图片、压缩包 | 解析崩溃、资源耗尽、路径穿越 | 大小/类型/解压上限；隔离解析；规范化路径；失败不覆盖原件 |
| 模板执行任意代码 | 文件窃取、联网外传、不可重复渲染 | 一期只允许声明式 JSON/DSL；无 eval/Function/任意 JS；规则白名单与预算 |
| Prompt injection/恶意参考材料 | 模型越权调用工具或泄露资料 | 内容与指令分离；工具 allowlist；最小上下文；用户确认高风险动作；输出不直接执行 |
| 模型幻觉或格式错误 | 错误内容、错误引用、破坏文档 | schema 校验、确定性 validator、diff/accept/reject、undo、出处和用户裁决 |
| 路径穿越/符号链接/覆盖 | 修改项目外文件或覆盖用户原件 | 规范化并校验授权根目录；原子写入；另存/备份；覆盖前确认 |
| 凭证泄露 | 费用与数据风险 | OS 安全存储；日志脱敏；提交扫描；项目包和导出排除密钥 |
| 日志泄露正文 | 隐私或商业秘密外泄 | 日志只记 ID、错误码和必要元数据；正文默认不上传；诊断包先预览 |
| 依赖/更新供应链攻击 | 执行恶意代码 | 锁版本、官方来源、哈希/签名、漏洞与许可证扫描、最小依赖、SBOM |
| 资源耗尽 | 超大文档/图片/表格导致卡死 | 输入上限、worker 隔离、取消/超时、内存/页数预算、渐进处理 |
| 多窗口/并发写入 | 数据损坏、覆盖新版本 | 单写者/锁或事务策略；版本检查；崩溃恢复；真实并发测试 |
| 导出不完整或字体缺失 | 对外交付失真 | 字体预检/嵌入检查、页面 validator、固定渲染回归、导出后复检 |
| 备份不可恢复 | 用户误以为安全 | 在干净环境真实重导入；版本/迁移测试；恢复演练 |
| 壳层越权 | Web 内容获得平台高权限 | host allowlist、来源校验、参数 schema、权限状态、取消与审计 |

## 4. 安全不变量

1. 导入只读原件，先复制/解析到受控区域；任何转换不得原地覆盖。
2. host 能力默认拒绝，按能力授权；Web 内容不能取得通用文件系统或 shell 权限。
3. 模型只能调用当前任务显式加载的高层语义工具，不能执行任意命令或任意路径读写。
4. 第三方模板无网络、文件、系统或动态代码能力。
5. 删除、覆盖、迁移、批量修改和正式发布均提供预览/确认/恢复边界。
6. 安全检查失败时采取最小权限降级，不“为了完成任务”自动放宽限制。

## 5. 后续必须扩展的时点

- G1：加入具体框架安全配置、Electron context isolation/CSP、依赖扫描和文件权限测试。
- PoC-B：加入项目数据库、并发、崩溃恢复、知识包和模型工具威胁用例。
- G3：加入代码签名、自动更新、下载完整性、隐私政策和漏洞响应。
- 同步/模板市场：单独加入认证、多租户、冲突、恶意模板、审核和撤回机制。
