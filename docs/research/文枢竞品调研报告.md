# 文枢（Wenshu）竞品调研报告

- 日期：2026-07-20
- 目的：在生产代码铺开前，验证"AI 原生专业成品系统"是否已有同赛道竞品，校准纲领 v1.0 的竞品判断
- 方法：四轮中英文检索（AI 长文/排版工具、WPS AI、公文工具、PPT 工具、通用 Agent、知识层、排版引擎、垂直场景），共约 90 个来源
- **来源警示：本领域中文检索结果中营销软文占比极高（尤其 AI 标书、WPS 教程类站点），功能宣称多未独立验证。本报告对软文来源的结论均标注"宣称"，不作为事实采信。**

---

## 一、核心结论

**1. 没有发现与文枢全组合撞车的竞品。** "AI 原生 + 确定性排版 + 页面级校验 + 本地优先 + 模型中立 + 中文长文通用成品"这个组合，在中文和国际市场均未发现占据者。首战场景（10–30 页中文通用专业报告的排版交付）空白确认。

**2. 但有一个必须正视的发现：文枢的架构已被"AI 标书垂直派"完整实现并商业化。** 云境标书 AI、易中标（微盟）、钛投标等工具的全流程是：招标文件解析（语义理解）→ 智能目录（结构生成）→ 内容撰写（模型生成）→ **智能排版引擎**（字体统一、目录链接、页码编排、表格规范化、一键导出 Word）→ **废标风险检测（校验规则引擎）** → 企业资源库（知识层沉淀）。这与纲领 v1.0 的系统五层几乎同构。含义是双面的：
- 好消息：路线被真实市场验证——"解析→生成→排版→校验→导出"的闭环有人跑通了，且在收费（宣称 40 分钟出 120 页成品）；
- 坏消息："AI 原生成品系统"这个 pattern 并不独特，垂直玩家已经拥有排版引擎、校验规则库和企业知识库，**从标书横向扩展到通用报告只差一个产品决策**。

**3. 最近邻的大厂产品是百度橙篇。** 十万字长文生成、指定模板整理全文格式、一键校正、查重，依托文库 12 亿文档。它是"云端原生派-长文"方向最贴近首战场景的产品，但其重心在内容生成与学术场景，编辑仍是手工 Word 式，无页面级校验、无本地、无模型中立。

**4. 付费意愿与价格锚点已被验证。** Genspark 宣称 45 天 3600 万美元 ARR（未经审计的宣称）；钛投标 9.9 元/次、云境 88 元/月、新华妙笔 98 元/月、ChatPPT 199 元/年。**按次/按交付收费的模式在成品类工具中成立**，支持纲领"首期付费标的 = 专业交付能力"。

**5. 所有竞品均无鸿蒙原生版本。** 卡位判断维持。

## 二、竞品地图（五派 + 一层基础设施）

### A. 补丁派巨头（受结构约束，但最有钱）

| 产品 | 状态 | 与文枢的关系 |
| --- | --- | --- |
| WPS AI（灵犀） | 宣称有"智能排版"（识别标题层级、套用模板）、公文起草一体化、智能论文助手；WPS AI 2.0 宣称 2026 Q3 提升长文档语义连贯性。**注意：相关信息多来自低权威教程站，属宣传口径** | 判断六的直接检验对象。用户 n=1 实测体验差，但其资源和装机量决定了它永远是最危险的"万一" |
| Microsoft 365 Copilot | 内容生成与摘要为主，排版能力薄弱 | 国内中文场景影响小 |
| Google Workspace Gemini | 同上 | 国内基本无影响 |

### B. 云端原生派 · 演示导向（红海，但与文枢无交集）

Gamma（中文支持弱、需翻墙、导出 PPT 常跑版）、Tome、Beautiful.ai、Canva；国产 AI PPT 已是血海：ChatPPT（199 元/年）、AiPPT、博思 AIPPT、boardmix、笔灵 PPT、iSlide、Kimi PPT、讯飞智文、百度文库 AIPPT、WPS AIPPT、豆包等二十家以上。**全部是 PPT，无一做长文排版**——文枢"不做演示模块"的决策反而避开了最挤的赛道。

### C. 云端原生派 · 长文导向（最近邻所在）

| 产品 | 定位 | 与文枢的差距 |
| --- | --- | --- |
| **百度橙篇** | 十万字长文生成、深度编辑、指定模板整理格式、查重，学术/报告场景 | 无确定性页面校验、无本地、无 BYOK、无出处系统、编辑仍手工。**首战场景的最近邻，必须实测** |
| 讯飞智文 | 文档+演示联动生成，积分制 | 设计与排版能力口碑弱 |
| 秘塔写作猫 / 笔灵 AI | 写作润色工具 | 不做排版交付 |
| Notion AI / Craft / Lex / Type.ai / Jasper | 英文内容生产 | 中文市场基本无影响 |

### D. 通用 Agent 派（下限抬高者）

Manus（报告与网页生成）、Genspark（AI Slides/Docs/Sheets，$24.99/月）、商汤办公小浣熊（企业任务智能体，可私有化）、ChatGPT/Gemini/Perplexity 的 Deep Research（ChatGPT 已支持 PDF 导出但用户反馈排版稳定性不佳、会跑版）。共同特征：**能生成内容、能糙导出，无模板系统、无页面校验、无本地、成品即死物**。它们抬高了用户对"AI 出稿"的期望值，但交付质量恰好是文枢的主攻点。

### E. 垂直全流程派（本次调研最重要发现）

| 子类 | 代表 | 状态 |
| --- | --- | --- |
| **AI 标书** | 云境标书 AI、易中标（微盟）、钛投标、快标书、慧中标、智标领航、链企 | **文枢架构的垂直完整实现**：解析→目录→生成→智能排版→废标校验→导出→企业知识库。按次 9.9 元起、月卡 88 元档。功能宣称均来自软文，未独立验证 |
| AI 公文 | 新华妙笔（新华社系，98 元/月）、笔墨公文 | 体制内公文垂直，强规范强模板；文枢首战明确不碰公文，边界清晰 |
| 公众号排版 | 秀米、135 编辑器、壹伴 | 新媒体视觉排版，非打印级成品 |
| Word 插件派 | 不坑盒子（免费，集成 DeepSeek/豆包/千问，自定义规则一键排版，含公文专项） | **补丁派的游击队**：证明"自定义规则一键排版"需求真实存在，但它长在 Word 的扁平模型上，恰好演示了判断六的天花板 |

### F. 本地优先 / 知识层派

AFFiNE（两轮检索均无近期声量，势头不明）、Obsidian + MCP 生态、思源笔记（可接 Ollama/DeepSeek，插件式 AI）、Tana、Anytype、FlowUs、语雀。**无一具备成品引擎**——存储与关系强，排版与交付无。文枢的知识层设计仍属空位。

### G. 排版基础设施（非竞品，是可用资产与参照）

Typst（0.15 版，开源、增量编译、模板生态活跃，证明"确定性排版 + 模板系统"路线在工程上成立）、LaTeX/Overleaf、Paged.js/WeasyPrint。**建议：PoC-A 排版引擎选型时将 Typst（WASM）列入评估对照**——此项属工程细节，不触动冻结纲领，进工程文档。

## 三、威胁等级评估

| 威胁 | 等级 | 理由 |
| --- | --- | --- |
| 标书派横向扩展到通用报告 | ★★★★ | 已有排版引擎、校验规则、知识库，横向化只差产品决策；但它们扎根 B2B 投标场景，转向意愿未知 |
| 百度橙篇迭代出"专业排版交付" | ★★★★ | 最近邻，大厂资源，长文场景重合；目前排版是软肋 |
| WPS AI 2.0 长文档能力兑现宣传 | ★★★ | 判断六的反面；Q3 2026 见分晓，须实测 |
| 通用 Agent 把"糙排版"做到够用 | ★★ | 短期做不到页面级，长期是下限压力 |
| AFFiNE 等知识层补成品引擎 | ★★ | 目前无声量，但架构最接近 |
| 国际英文市场竞品 | ★ | 首战中文场景，暂无关 |

## 四、对纲领 v1.0 的影响评估

1. **竞品三分应扩为五分**：补丁派、云端原生派（演示/长文）、通用 Agent 派、**垂直全流程派（新增）**、知识层派。不触碰冻结纲领正文，此增补记录于本报告与决策记录。
2. **判断六维持**：不坑盒子与 WPS 插件生态反而提供了补丁天花板的新证据——一键排版需求真实，但在 Word 扁平模型上只能做到"规则套用"，做不到语义理解加页面校验。
3. **首战假设维持且强化**：空白确认；但对照任务应扩充（见行动建议 1）。
4. **商业模式获旁证**：按次/按交付收费在标书派成立（9.9 元/次），"交付级导出属专业版"的定价直觉有市场参照。
5. **鸿蒙卡位维持**：全部竞品无鸿蒙原生版本。

## 五、立即行动建议

1. **扩充 PoC-A 对照任务**：原设计只对照"WPS/Word 人工排版"。建议增加两个 AI 对照组——WPS 智能排版（灵犀）与百度橙篇，同一份草稿、同一套要求，记录三者（人工 / WPS AI / 橙篇）的时间与可交付度。这让首战验证同时成为竞品验证。
2. **研究标书派产品细节**：云境、易中标的"目录生成→排版→校验→导出"交互流程是现成的参考系，它们的用户差评（软文的反面）更值得挖——差评即需求。
3. **建立季度竞品监控**：按第六节清单执行，每季度复核一次，结果记入决策记录。
4. **决策记录增补**：将本报告结论备案为决策 #2（竞品态势与监控机制）。
