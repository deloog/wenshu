# ADR-0021：PB-06 语义审计事件与出处链

- 日期：2026-07-29
- 状态：已实现，待 Claude 独立审计

## 决策

1. `@wenshu/semantic-audit` 维护进程内的语义事件流；它不是编辑历史、CRDT update 或持久化层。
   事件只在 AI 裁决、人工后续修改、材料关联等具有责任意义的边界写入，不存在按键 API。
2. 写入必须经 `@wenshu/project-contract` 的 `semantic_audit_event` 校验。PB-05A 的 0.2 hash
   subject 原样消费：普通文档变更为 document，模板变更只能为 template。
3. AI 裁决从 PB-05 字段级 diff 中仅提取稳定 node ID；不保留 diff 值、请求、prompt 或正文。出处
   查询按 node ID 汇集 AI 裁决、人工后续事件、材料引用与材料存在状态。

## 后果

- 审计可回答来源、AI 改动范围、人工后续修改及材料是否仍存在；它不能重放正文或替代事务/同步日志。
- 密钥与全文没有字段入口，未知字段由 Schema 拒绝。真实存储、序列化和知识包闭合继续由 PB-08~11 承接。
