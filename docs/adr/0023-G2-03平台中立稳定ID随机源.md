# ADR-0023：G2-03 平台中立稳定 ID 随机源

- 日期：2026-07-30
- 状态：已实现，待 Claude 独立审计
- 关联：宪法 6/11、G2-03、ADR-0015、PB-02～PB-05

## 决策

`@wenshu/semantic-editor` 的默认 `RandomIdAllocator` 使用
`globalThis.crypto.getRandomValues(new Uint8Array(16))` 生成 16 个随机字节，并以 32 个
十六进制字符编码。删除对 `node:crypto` 的导入；不改变 `IdAllocator` 接口、ID 前缀或
既有文档契约。

## 依据

Web Crypto 是浏览器、Electron 与锁定 Node 24.17.0 均可用的平台中立 API。16 字节仍为
128 位随机值，与此前 `randomBytes(16)` 的熵长度相同；ID 从不接收位置、索引或文档内容，
因此不改变 PB-02 的“ID 内在、非位置派生”红线。

## 对既有结论的影响

- PB-02 的 adapter、稳定 ID 属性测试与 schema 有效性结论不变；新增测试只确认默认分配器
  保持 `prefix_` + 32 位十六进制形状且连续分配不重。
- PB-03 的事务、undo/redo 与取消边界不变：它继续接收同一 `IdAllocator` 抽象。
- PB-04 的模型唯一写路径与 PB-05 的 preview diff 不变；`editor-diff` 继续通过同一默认
  分配器创建隔离预览，只是不再把 Node 实现固化进 L1 生产路径。

## 已知边界

G2-03 只检测模块说明符依赖方向。`process`、`Buffer`、`process.getBuiltinModule()` 与
`globalThis.process` 的 Node 全局能力本轮显式不检测；其使用仍受人工审计与后续门禁约束。
