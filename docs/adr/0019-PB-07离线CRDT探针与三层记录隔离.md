# ADR-0019：PB-07 离线 CRDT 探针与三层记录隔离

- 日期：2026-07-29
- 状态：已实现，待 Claude 独立审计
- 决策：以隔离的 Yjs 13.6.27 最小探针验证双副本离线合并与稳定 ID/事务映射；不将候选接入产品供应链，也不实现自动同步。

## 决策与边界

1. 探针位于 `probes/pb-07-yjs/`，不是 pnpm workspace package。根 `pnpm-lock.yaml`
   和 `sbom/sbom.json` 保持不变；候选只能用其独立 `package-lock.json` 安装和复跑。
2. 两个 `Y.Doc` 从相同种子状态离线分叉：一方改写已有稳定节点，另一方插入新稳定节点。
   双方交换真实 `encodeStateAsUpdate` 数据后，探针对账完整节点/事务状态收敛，且每个
   `affectedNodeIds` 都仍指向一个存在的 G1-04 形式节点 ID。
3. 编辑历史、CRDT 合并记录、语义审计事件分别由
   `records.schema.json` 的独立 `edit_history`、`crdt_merge` 与 `semantic_audit` schema
   定义，均 `additionalProperties: false`。因此事务 ID 不得进入语义审计，CRDT update/
   state-vector 数据也不得进入编辑历史或语义审计。
4. 这只是候选可行性证据：没有网络 transport、peer discovery、后台同步、持久化、UI、
   冲突裁决产品策略或生产 API。它尤其不能被表述为 Alpha 自动同步已经实现。

## 复现命令

```powershell
Set-Location probes/pb-07-yjs
npm ci --ignore-scripts
npm test
```

探针失败（包括 ID/事务映射无法稳定或两副本状态不收敛）时，Yjs 不得被硬凑为候选；应如实
换候选并重新评审 ADR。
