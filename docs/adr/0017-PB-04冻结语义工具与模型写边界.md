# ADR-0017：PB-04 冻结语义工具与模型写边界

- 日期：2026-07-29
- 状态：已实现，待 Claude 独立审计
- 决策：模型写入只可经 `@wenshu/semantic-tools` 的六个冻结工具，再编译为
  `TransactionManager` 的 `ai` 事务。

## 决策

1. 模型可见工具严格为 `rewrite`、`insert`、`outline`、`table`、`citation` 与
   `move_subtree`。没有动态注册、任意命令或第七个工具；每个输入均以精确字段集
   解码，未知字段、原型对象、getter 与非预期类型一律拒绝。
2. `ModelToolGateway` 私有持有事务 manager 和最小权限集。调用方只取得工具定义和
   净化的 committed/rejected 结果，不能取得 manager、raw command、`/internal`、
   DOM、存储句柄、文档快照或内部错误。
3. 编译器只经公开 semantic-editor adapter 读取当前快照，并把六类意图编译为
   PB-03 `EditorCommand`；执行固定为 `manager.execute("ai", ...)`。PB-03 继续是
   schema、稳定 ID、原子提交/回滚的唯一权威来源。
4. 权限按工具名和明确可写节点 ID 的交集判定，无通配或猜测。目标不存在、目标类型
   不合法、参数越界和无权限均在提交前拒绝。循环移动虽能编译为命令，仍由 PB-02/PB-03
   的真实事务守卫回滚，网关不泄露内部失败细节。
5. 对抗文字只是文档内容，不解释为权限或命令；试图通过额外 `command`、`path`、
   `operation`、`tool` 字段或未知工具改变结构时，严格解码拒绝。临时 ID 仅用于编译
   中构造合法源块，PB-02 插入时重新分配内在随机 ID，临时 ID 从不进入已提交文档。

## 后果

- PB-04 不实现模型、UI、diff、持久化、协同或审计出处。宿主可给模型一个 gateway，
  但不得给它其他应用依赖；这条模型侧硬锁闭合 PB-03 的 internal 子路径观察。
- 工具输出包含受影响节点 ID，供后续增量分页消费；不据此实现分页。
- 新包仅引用既有 workspace 包，未新增第三方运行时依赖；lockfile/SBOM 仍须由供应链
  门禁重建核验。
