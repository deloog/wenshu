# ADR-0009：PA-10 图片检查严重级、比例容差溯源与转换红线

- 日期：2026-07-27
- 状态：已接受（实施决策，随 PA-10 独立审计复核）
- 关联：路线图 PA-10 行、ADR-0006（证据契约 v1.1.0 成员标记与 paintBBox）、ADR-0007（P1 诚实降级先例）、ADR-0008（三重防线先例）、PA-10 开工指令（Claude 门禁定义）

## 背景

PA-10 要求实现图片语义完整性检查：①图↔题注同页 ②来源紧随题注且同页
③比例（paintBBox 宽高比 vs 源 SVG viewBox 固有比）④清晰/可读性（仅
确定性面自动）⑤受控 SVG→等价资源转换红线与内容/来源忠实。开工指令
钉死两条先决约束：与 PA-07 的分域红线（几何越界/遮挡一律不重判）与
诚实门（无确定判据的判定显式降人工）。三个设计问题需要书面化：

1. **严重级**：五个新检出码为什么全部定 P1 而不是 P0。
2. **比例容差**：paintBBox 比值与 viewBox 固有比之差允许多少，依据是什么。
3. **转换红线与停止条件**：基线无转换时如何如实判定，转换若发生如何
   保证不可静默通过。

实施期签署基线探针实测（留痕于
[PA-10 实施记录](../audits/PA-10-implementation-record.md)）得到决定性事实：

- 基线 2 图均为 `vector-figure`：p7 mcid=0（成员 58 run）、p9 mcid=4
  （成员 80 run）；题注 run 为**非成员**（figcaption 的 /P 不在 /Figure
  span 内），阅读序紧随图成员（p7：成员 ro 3807..3864 → 题注
  3865..3867 → 来源 3868..3941；p9 同构）；来源段与题注阅读序无夹块
  （gap=0）。
- 成员 run 归一拼接与源 SVG 文本（extractSvgText + normalizePdfText
  口径）**逐字相等**（58/58、79/79）；成员字体全部嵌入。
- paintBBox 宽高比与 viewBox 固有比实测偏差 <0.0001（浮点尾数级）：
  p7 1.7647058823529413 vs 1200/680=1.7647058823529411；p9 两侧同为
  2.3076923076923075。
- 基线 asset 为 .svg 原件（manifest sha256 锚定），证据 `kind` 为
  vector-figure 且成员文本齐备：**渲染管线直渲 SVG，无任何受控转换**。

## 决策

1. **严重级证成：五码均 P1**（`P1_FIGURE_CAPTION_SEPARATED` /
   `P1_FIGURE_SOURCE_SEPARATED` / `P1_FIGURE_ASPECT_DISTORTED` /
   `P1_FIGURE_CONTENT_MISMATCH` / `P1_FIGURE_FONT_NOT_EMBEDDED`）。
   题注/来源孤立、比例失真、图例与源不一致、字体未嵌入均不构成内容
   丢失（题注/来源/图内文本整体缺席由 PA-07 `P0_CONTENT_MISSING` 判，
   本任务对「缺席」一律只降人工不重复判定），也不构成几何越界或遮挡
   （PA-07 P0 域，见决策 4）；违反的是模板声明式图文同页规则
   （`figure_keep_with_caption`）、golden 声明意图（来源紧随题注）与
   源忠实约定，属排版/呈现质量缺陷，与 ADR-0007/0008 的 P1 口径一致。
2. **比例容差溯源：`FIGURE_ASPECT_TOLERANCE = 0.01`（绝对比值差）**。
   依据：Chromium/Skia 对 `<img>` 内 SVG 的等比缩放是精确仿射变换，
   不失真时绘制宽高比与 viewBox 固有比**数学相等**；paintBBox 构造
   （绘制算子路径点 + 成员 run bbox 并集，ADR-0006）只引入 pt 取整
   噪声。基线实测偏差 <0.0001，容差余量两个数量级——容差只吸收取整
   噪声，不能放行任何可见失真（15%/3% 失真 fault 均检出，0.4% 贴容差
   合法不报，均有决定性测试）。源 SVG 无合法 viewBox 时无确定判据，
   fail-closed 降 `P1_FIGURE_ASPECT_REVIEW` 人工核验（不猜）。
3. **转换红线与停止条件**：内容忠实的自动判据是「图成员 run 归一拼接
   === 该图自己的源 SVG 文本」（PA-05 normalizePdfText 归一口径复用，
   文档侧 figure-svg 期望块携带源文本）。受控转换若改变内容或来源——
   光栅化丢矢量文本（成员 run 归零而源有文本）、图例/数据被改、平台间
   悄悄换图——成员文本必然不等于源，`P1_FIGURE_CONTENT_MISMATCH`
   **必然触发且无法静默通过**；此时必须停止并触发风险评审、如实记录，
   不得伪装通过（开工指令红线）。**基线停止条件如实判定不触发**：管线
   直渲 SVG（asset 为 .svg 原件、kind=vector-figure、成员文本与源逐字
   一致），无转换发生，证据钉定于实施记录。与 p0-content 的分域（如实
   说明）：p0-content 是全局有序存在性（块路径定位），本规则是逐图绑定
   对账（figure 定位）——p0 无法识别「文本全局仍在但绑错了图/图被换」；
   单点文本篡改两面同报（P0_CONTENT_MISSING + P1_FIGURE_CONTENT_MISMATCH）
   属两个受门禁各自要求的独立面如实并存，不静默其一。
4. **与 PA-07 分域正交证成**：PA-10 不实现任何出页/出版心/遮挡判定。
   「来源越界」在 PA-10 的语义仅为**页归属**（题注/来源 run 的
   pageIndex ≠ 图 pageIndex、阅读序颠倒、题注与来源间夹块），是 MCID/
   阅读序事实而非几何事实；几何越界（paintBBox 出页/出版心）与图遮
   文本由 PA-07 `P0_OUT_OF_BOUNDS`/`P0_OVERLAP` 独占。分域猎杀测试
   （构造 figure 出版心、非成员 run 叠入 paintBBox）证实：PA-07 照报，
   PA-10 五条规则零发现。
5. **归属三重防线**（仿 ADR-0008，任一不过即歧义，歧义 fail-closed 降
   `P1_FIGURE_CAPTION_REVIEW`/`P1_FIGURE_SOURCE_REVIEW`）：①文本对齐
   ——归一整串匹配 + run 边界对齐 + 阅读序连续 + 单一 MCID 块（归一后
   零长 run 如纯空白仍计入场内，否则误杀合法段落——实施期实证修复）；
   ②阅读序——题注候选必须在图成员之后、来源候选必须在题注之后，取
   唯一候选，多候选即歧义；③几何一致性——同页题注必须在图绘制范围
   之下（topY ≤ paint 底边 + 1pt 取整容差），题注在图上方的异版式不
   自动判。来源块身份是文档侧声明式事实（figure 紧邻后继 + 归一文本
   「图N来源」前缀，golden-report L121 自述的待验证约束），非几何
   启发式；文档未声明来源块的图降人工（是否应有来源无法自动判定）。
6. **诚实门**：视觉清晰度无确定性/无源可测判据（模板未定义任何密度
   或清晰度阈值），自动面只覆盖二值可对账事实（矢量文本对账源、字体
   嵌入字段事实），其余逐图显式降 `P1_FIGURE_LEGIBILITY_REVIEW`（附
   paintBBox 尺寸/成员 run 数/最小成员字号证据），`*_REVIEW` 绝不入
   findings（类型+契约双保险，承接 ADR-0007）。基线新增人工项恰 2 条
   （2 图），PA-08 钉数 30→32，台账 PA-10-followups 承接 PA-J1。

## 后果

- 检出报告契约保持 1.1.0 零漂移：九个新码全部落在既有
  `^P[0-9]_[A-Z0-9_]+$` 码模式与既有 findings/manualChecks 双通道内，
  冻结 1.0.0 schema 与 P0 运行器产物不受影响。
- 比例检查的唯一源侧事实为源 SVG viewBox（`extractSvgAspectRatio`
  零依赖白名单解析，fail-closed）；零新增第三方运行时依赖。
- 转换留痕机制 = 本对账判据本身（任何改变内容/来源的转换必然变红）；
  平台间换图无合法静默路径。
- 已知边界（如实登记）：题注/来源判定依赖「图成员之后唯一候选」阅读
  序事实，正文逐字复述完整题注/来源全文且位于图后的文档会触发歧义
  降人工（不误报为缺陷）；来源前缀约定来自 golden 声明，其他文档约定
  需在各自模板/golden 层登记。
