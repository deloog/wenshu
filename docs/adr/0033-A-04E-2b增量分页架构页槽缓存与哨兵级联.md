## 1. 机制事实（本机探针 `a04e2b-incremental-probe.ts`，30 页/30,000 字语料 sha256 `4dedb1c2…6258`，Chrome/152 Win10——机制证据，非预算证据）

| # | 事实 | 数据 |
|---|---|---|
| F1 | **`pageRanges` 页级证据等价**：ranged print 的页内容与整份 print 同序页逐 run 全等（归一化 text/baselineY/bbox.x/fontSize） | 3 个区间（5-6/5-14/25-30）共 12,296 run 比对 **0 失配** |
| F2 | **字体资源 tag 不可跨打印比对**：每次 print 调用独立分配资源名 | 同批比对含 tag 则 12,296/12,296 全异 |
| F3 | **ranged print 不含文档大纲**：TOC 页码不能从 ranged print 测量 | `measureTocPageNumbers` 报 `PDF_EXPORT_PAGINATION_FAILED` |
| F4 | **打印成本随内容缩放但不均匀**：整份 30 页热打印 1820ms；2 页（含图）735ms；10 页 1243ms；附录 6 页 117ms；热 navigate 357ms | 成本是内容函数，不是均匀页函数；预算论证不得按页均摊 |
| F5 | 证据提取整份 30 页 ~95ms（18,681 run） | 页级对账在预算内可忽略 |

## 2. 架构决策

### D1 缓存形态：整份 PDF + 页证据索引 + 受影响窗 ranged print 槽，**不做跨文档 PDF 页拼接**

初次导出沿用 2a 签署管线（单遍回填，整份产物）。缓存三件事：① **未压印整份字节**（压印可重放，见 D4）；② 终态整份字节（旧预览显示源）；③ 逐页几何证据（`extractGeometry`，页 → run 序列，作受影响区定位与级联判定的索引）。

局部编辑后：只重渲染受影响窗（CDP `pageRanges`），产出**窗格 PDF**作为这些页槽的新显示源；未受影响页继续显示旧整份（查看器锚 `#page=N`）。**不发明跨文档 PDF 页拼接**——F1 已证页级等价可由对账门禁保证，拼接只是把等价性换成字节级复杂性而无验收收益。终稿导出（30s 预算）始终走整份管线，不经缓存。

### D2 受影响区计算：锚定定位 + 哨兵延伸，级联只认证据不认假设

输入 = 编辑事务 `committed.affectedNodeIds`（editor-transactions 既有）+ 旧逐页证据 + 新文档。

1. **定位**：取受影响块的锚文本在旧证据中定位首受影响页 P 与末触达页 Q；锚文本歧义/缺席即 **fail-closed 退整份重排**（8s 预算路径），不猜。
2. **哨兵延伸**：重渲染窗 `[P, Q+1]`（多打一页哨兵）。新哨兵页与旧 Q+1 页证据（F2 口径：不含 tag）一致且窗内页数差为零 → 级联在 Q 边界收束；不一致 → 窗延伸至下一页重打，直到收束或到末页（退化为整份，仍正确）。**终止性构造保证**（窗单调扩、上界 N）。
3. 页数差 d = 新窗页数 − 旧窗页数；d≠0 时 Q 之后所有页内容不变但页码偏移 d（F1 保证内容等价，哨兵保证边界）。

### D3 目录/页码更新：占位回填复用 + 锚定重测 + 移位核验

F3 排除了从 ranged print 量大纲。协议：

- 窗内标题页码：从窗格 PDF 逐页证据按标题锚文本重定位（歧义 fail-closed 退整份）；
- 窗后标题：页码 += d，并在旧证据上核验锚文本仍在移位后页（核验失败退整份）；
- 目录页槽：重打目录页（占位 `888` 不变），用新页码表经**既有 `backfillTocPageNumbers` 字节级回填**窗格 PDF——回填机制签署于 2a，此处只是作用于窗格；
- 页码表变化的**正确性对账**（ADR-0014 ④）：增量页码表 ≡ 同文档整份重渲的大纲测量表，十次确定性对账逐表比对，不采信增量自报。

### D4 页眉页脚压印：压印属交付层，预览由显示层统一覆盖（实施期机制修正）

实施期实证：ranged print 的字体子集只含窗页实际用到的字形，页眉 short_title
的 CJK 字符在窗格 PDF 中**无忠实字形表示**（`resolveStampReps` fail-closed 拒压），
「窗格绝对页码压印」机制上不成立。故：窗格/目录页槽产物保持内容级未压印字节；
预览显示层以绝对页码统一覆盖页眉页脚（工装职责）；终稿导出的压印永远走
整份签署管线。total 变化（delta≠0）场景 v1 直接退整份重排，不发明旧尾页改号压印。

### D5 旧预览协调与取消（ADR-0014 ①③）

- 后台任务期间旧预览（旧整份终态字节）保持展示与可操作；增量产物未完整通过哨兵核验前**不替换任何页槽**（stalePreviewRetained 契约语义）；
- 取消 = 既有 `AbortSignal` 链路（`RENDER_CANCELLED`→`PDF_EXPORT_CANCELLED`）；取消后不触碰缓存，同会话立即可再导出（2a 已有确定性测试形态，2b 对增量路径复刻）；
- 主线程不阻塞：渲染在浏览器进程，驱动侧全异步 CDP；工装实测后台任务期间 UI 事件响应延迟（见 §4）。

### D6 验证宿主（决策 #25 D1）：一次性验证工装

工装 = 真实编辑器（A-02 导入 + A-03 事务链产出 `affectedNodeIds`）+ 预览页槽面板 + 后台任务状态/取消按钮 + CDP 可驱动插桩点，显式标注「验证工装，非产品 UI」，不演化为 A-04。VM 批次由 Node 驱动脚本经 CDP 操作（沿用 2a 批次形态）。

## 3. 预算账目（1s 局部，以 VM 实测定局；本机数仅机制外推）

局部编辑（单块同长替换，窗=2 页含哨兵）全链 = 热 navigate（F4 ~0.36s）+ ranged print（内容函数，F4 0.1–0.7s）+ 页证据提取与比对（<10ms）+ 压印/回填（十 ms 级）。本机合计 ~0.5–1.1s。**VM 上是否 ≤1s 不在本机预言**——2a 经验 VM 慢于本机；若实测超预算，按决策 #18 D3 如实阻断登记，不放宽、不降质、不再 DEGRADE。

## 4. 诚实性门禁（审计猎杀方向自答）

1. **增量是不是真增量**：批处理插桩记录每次 print 的 `pageRanges` 实参——报「增量」的轮次必须真的只打了窗页；整份重打即如实登记为级联退化，不算增量达标样本。
2. **正确性不循环**：ADR-0014 ④对账以**整份重渲**为参照（独立路径），增量态逐页槽证据比对 + 页码表比对，双比对全等才算对账通过。
3. **确定性**：同编辑序列十次，逐次产物按持久会话口径（node ID 重编号，2a 签署口径并存不动）比对全等。
4. **缓存失效正确**：变异测试——伪造「哨兵误判一致」即必须检出页内容漂移；「页数变化未移位」即页码表对账必须红。
5. **语料诚实**：全程 30 页/30,000 字（sha `4dedb1c2…6258`），21 页数据不出现于任何预算结论。

### 4.1 tag-free 键逐字段口径（2026-09-16 修订，独立审计 A2B-F1）

`runKeyTagFree` 丢弃字段逐条依据（打印变异性实证，非统称 F2）：

| 字段 | 处置 | 依据 |
|---|---|---|
| `font.objectId` / `font.tag` | **剔除** | F2：每次 print 调用独立分配资源标识（同页 ranged vs 整份 697/705 不同） |
| `bbox.height` | **剔除** | 打印相关漂移：同页 ranged vs 整份实测 **20/705 不同**（hinter 微调） |
| `pageIndex` | 不入键 | 比较轴而非内容事实（槽位 PDF 页码为窗相对页号） |
| 其余全部字段（归一化 `text`、`baselineY`、`bbox.x/y/width`、`fontSize`、`blockOrder`、`viaActualText`、`figureMcid`、`font.family/weight/subset/embedded`） | **保留** | 同页 ranged vs 整份实测 **705/705 相同**（`family`/`weight` 按构造打印不变：子集前缀在 `geometry.ts` 解析期显式剥除）——收紧零误报 |

收紧的检出力（决定性变异形态已入 `incremental.unit.test.ts`）：换字体族/字重、字形宽度漂移、ActualText 表示、/Figure 成员（决策 #10 域）、丢失内嵌——六类从判等变为必判不等。影响边界（审计实测）：以严口径全量扫描批次 30 条编辑共 70 个页对，「旧宽口径判等而严口径判不等」= **0**——宽口径盲区在 run-2b-5 从未触发，④「达成」结论不被推翻；本修订消除的是口径隐患，不是追改批次结论。

## 5. 边界与不做什么

- 不触碰 PoC-A 签署冻结物字节；不改 `normalized-pdf-sha.mjs` 签署口径；不改检查契约。
- 不接 Alpha 排版依赖（决策 #11A）；工装不演化产品 UI（决策 #25 D1）。
- 不做跨文档 PDF 拼接、不做 DOM 原位更新省 navigate（若 VM 实测预算不达标，作为后续裁选项登记，不在本棒夹带）。
- ux-state 契约注释中「leaves the implementation slot for A-04」的实现棒已演化为 A-04E-2b，本 ADR 交代口径，契约字节不动。
