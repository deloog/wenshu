# ADR-0007：PA-08 检出报告契约 v1.1.0 与 P1 诚实降级（manualChecks）

- 日期：2026-07-26
- 状态：已接受（实施决策，随 PA-08 独立审计复核）
- 关联：PA-08 开工指令（诚实门=命门）、ADR-0006（additive 契约纪律先例）、PA-04 已登记近似（`heading_keep_with_next_lines` → CSS `break-after: avoid`）、路线图 PA-08 行（「无法确定性判断的降为显式人工检查，不伪装自动覆盖」）

## 背景

PA-08 要求消费 PA-06 v1.1.0 证据实现 P1 检查：标题与正文分离、孤行/寡行、
异常空白/稀疏页。开工指令把**诚实门**定义为命门：凡无法确定性判定的 P1
必须显式降级为人工检查项并如实标注，不得用启发式阈值冒充自动覆盖——且
「报告区分自动判定与人工核验」要求契约层面两个通道可分机器识别。

实施期用签署基线探针实测（留痕于 PA-08 实施记录）得到三条决定性事实：

1. **标题阈值灰区真实存在**：模板 `heading_keep_with_next_lines: 2`，但 PA-04
   已登记 CSS 无「保留下 N 行」等价物、只发射 `break-after: avoid`（保证
   ≥1 行）。基线上 10 处标题后继同页行数落在 1..N-1 区间（8 例标题后接
   1 行子标题、2 例标题后接单行完整段落）——按模板字面值自动判定会把
   已登记近似造成的合法排版报成违规；按 0 行判定则丢失模板意图信息。
2. **稀疏无模板定义**：`max_consecutive_sparse_pages: 1` 只约束连续页数，
   模板全文没有密度阈值。基线合法页密度实测 2.0%（封面）~45.3% 连续分布，
   任何切分阈值都无溯源依据。
3. **跨页段落归属不能靠几何**：`blockOrder` 按页重置，跨页段落身份唯一
   可靠来源是文档侧文本匹配；封面与正文一级标题同文（实测），正向游标
   会把正文标题误归属到封面页。

## 决策

1. **报告契约 additive 升级 v1.0.0 → v1.1.0**：新增必需字段 `manualChecks[]`
   ——人工核验项 `{ruleId, code(P1_*_REVIEW), pageIndex, nodeRef, reason, basis}`。
   `reason` 只能是静态口径文本（为何无法自动判定），schema 限长 200 字符；
   人工核验项的存在既不是通过也不是发现。契约纪律完全沿用 ADR-0006：
   1.0.0 schema 原样冻结保留（`check-report-1.0.0.schema.json`，仅 title 因
   生成命名调整为 `WenshuCheckReportV1_0_0`），reader 双版本分发，语义校验
   扩展为 findings 与 manualChecks 的 ruleId 均须属于执行规则集。
2. **P0 产物不回填**：P0 运行器继续生产冻结的 1.0.0 报告（PA-07 签署行为
   零漂移）；manualChecks 是 P1 域概念。P1 运行器生产 1.1.0。
3. **P1 自动判定只覆盖确定性核心**：
   - `P1_HEADING_SEPARATED`：标题同页后继正文行数 = 0（违反渲染器实际承诺
     的 ≥1 行不变量，模板 `heading_keep_with_next_lines > 0` 的确定性核心）。
   - `P1_ORPHAN` / `P1_WIDOW`：跨页段落页尾/页首保留行 < 模板
     `orphans` / `widows`（阈值直接取冻结模板值，贴阈值合法）。
   - `P1_EMPTY_PAGE`：整页零文本 run 且零 figure（二值事实；当前模板没有
     任何会产生空白页的构造）。
4. **显式人工降级两条**：标题后继 1..N-1 行灰区 → `P1_HEADING_KEEP_REVIEW`
   （附同页行数与模板 keepN）；稀疏判定整体 → `P1_SPARSE_DENSITY_REVIEW`
   逐页密度证据（文本/图形面积、版心占比、模板 maxConsecutiveSparsePages），
   不设任何密度阈值。规则被禁用时其人工核验项一并回退。
5. **块归属用反向游标匹配**（`lastIndexOf` 自后向前，游标严格指向前次
   命中之前）：同文重复（封面/正文同标题、未来 PA-11 目录条目先于真实
   标题）时真实排版位置是文本流中较晚的出现。行聚合按 baselineY 2pt
   聚类（与 p0-overlap 同视觉行口径一致），正文行排除 figure 成员 run
   （解析期事实，非几何推断）。未命中块跳过——内容缺失是 P0 域。

## 后果

- 签署基线 P1 自动发现 = 0；人工核验项有界钉数（10 标题灰区 + 20 逐页
  密度 = 30），随基线 sha 锚定稳定，作为审计可重放基线。
- PA-12 汇总门禁消费两个版本：P0 报告（1.0.0）+ P1 报告（1.1.0）；
  「P0+P1 检出」只计 findings，manualChecks 不计入自动检出数。
- 已知边界：标题后紧邻表格/图片块跳过（PA-09/10 专项域，不夹带）；
  quote 的 attribution 短行不参与孤行寡行；同文段落反向匹配取较晚出现
  （确定性口径，极端构造下可能归属较晚一处——数值依据仍可人工复核）。
