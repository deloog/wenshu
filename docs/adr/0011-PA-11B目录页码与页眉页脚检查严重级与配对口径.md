# ADR-0011：PA-11B 目录/页码/页眉页脚检查严重级与配对口径

- 日期：2026-07-28
- 状态：已接受（实施决策，随 PA-11B 独立审计复核）
- 关联：路线图 PA-11 行、ADR-0010（页码派生与压印补偿）、ADR-0007（诚实门）、ADR-0008/0009（严重级证成先例）、PA-11B 开工指令

## 背景

PA-11B 消费 v1.1.0 证据 + 文档模型 + 冻结模板，对 PA-11A 产出的目录、
页码与页眉页脚压印做**检查**（只检测、不代改、不手写页号）。三个设计
问题须书面证成：严重级归 P0 还是 P1；目录条目与正文标题如何确定性
配对；与 p0-content 的目录文本存在性如何分域。

## 决策

### 1. 严重级一律 P1（导航/参照忠实域）

目录页码错、页脚页码错、目录缺/多项、页眉页脚不一致——**正文内容本
体完整可读**，缺陷后果是误导导航与页码参照，属排版质量/忠实域：

- P0 域（PA-07）锚定内容正确性：缺失/重复/乱码/越界/遮挡，对应模板
  validators 的 content_complete/no_duplicate/no_overflow/no_overlap；
  `toc_page_numbers_match` 是独立验收项，不在 P0 内容域。
- 与 PA-08~10 的 P1 证成同构：缺陷不损毁交付物内容，但违反冻结模板
  意图且可确定性定位。
- 不设 P1_TOC_* 自动豁免口；严重级不因「只是导航」降 P2——P 体系只有
  P0/P1 两档（PA-07 冻结）。

### 2. 目录条目 ↔ 正文标题：tocIndex 文档序配对（禁文本猜测）

- `collectTocEntries`（document-model 唯一收录真源）给每个应入目录的
  section 一个文档序序号；expected-content 装配时把该序号同时钉在
  `toc-entry` 期望块与 `section-title` 期望块（`tocIndex` 可选字段，
  additive）——两侧同源同序，配对零猜测。
- 同名标题不构成歧义：配对按文档序不按文本；归因（反向游标
  lastIndexOf）把目录页出现归 toc-entry、正文出现归 section-title，
  两者天然分离（目录页在阅读序上晚于封面/前置、先于后续正文）。
- fail-closed：任一侧未归属（目录项未渲染/标题未渲染/标题跨页异常），
  该条目页码对账降 `P1_TOC_PAGE_REVIEW` 人工，不猜不藏。

### 3. 与 p0-content 的分域

- p0-content 管「目录文本在不在」（整串对账，正文级存在性）；PA-11B
  管「目录结构与页码对不对」（条目↔标题双向对应、标注页码===实际
  印刷页、页脚===物理页）。同一「缺项」事实可能同时触发两域——
  p0-content 定位到缺失文本区间，PA-11B 定位到条目/标题 ref 与数值
  依据（期望页 vs 标注页），判据与定位粒度不同，不构成重判。
- PA-11B 不检查目录条目的字级内容正确性（错字归 p0-content 对账域）。

### 4. 压印读取口径（与排除口径同一单源）

- P0/P1 内容规则用 stamp-scope **排除**压印；PA-11B 的
  p1-stamp-consistency 用同一 `STAMP_FONT_TAG_PREFIX` 单源常量
  **选中**压印 run——识别依据是解析期事实（font tag），禁止几何
  启发式（位置/字号猜测）；两个方向共用 stamp-scope.ts 一处实现。
- 页眉文本期望值来自 front matter `short_title`（markdown-import
  元数据声明值，经输入 `headerText` 传入）；输入缺该值时文本对账
  降 `P1_STAMP_REVIEW` 人工（诚实门），一致性（存在/位置/逐页均匀）
  仍可自动判定。
- 编号语义（PA-11A 钉定）：页码 = pageIndex+1 物理页码，封面计入；
  `cover_own_page`/`toc_start_new_page` 只产生布局分页，不产生编号
  偏移；封面（pageIndex 0）豁免压印（模板 cover_own_page 溯源）。

### 5. 页码标注的定位

目录条目页码是渲染派生值（不进期望块，PA-11A 装配口径）：条目行内
标题 run 之后、下一条目标记之前、归一文本为纯数字的 run 即标注；
恰好一个方可对账，零/多/夹非数字 → 降人工（不猜）。

## 备选与拒绝理由

- **P0 归级**：页码错不损毁内容本体，归入会破坏 P0 内容域语义
  （P0 不可豁免性会被导航类缺陷稀释），排除。
- **文本相似度配对**：同名/近似标题下不可判定，违 fail-closed，
  排除（tocIndex 文档序配对代之）。
- **TOC 结构进证据契约**：证据契约是纯提取事实（禁质量判定），
  目录语义归属检查器从文本 run+文档模型重建，保持契约面不膨胀，
  排除 additive 扩字段。
- **几何识别压印**（按 y 位置/字号）：承接硬约束禁止，单源 tag 常量
  代之。

## 后果

- report-checks 新增 3 条规则（p1-toc-reconcile/p1-toc-page-match/
  p1-stamp-consistency）+ 12 个新码（均合 `^P[0-9]_[A-Z0-9_]+$` 既有
  模式，**检出报告契约保持 1.1.0 零漂移**，PA-10 先例）。
- expected-content additive 增 `tocIndex` 可选字段；P1CheckInput
  additive 增 `headerText?`/`stampRuns?` 可选字段（runner 装配）。
- 签署基线（TOC 36/36、页脚 20/20 正确）→ 新规则 0 自动发现、
  0 新增人工项（钉数 33 不回潮）。
