# ADR-0016：PB-03 统一编辑事务边界

- 日期：2026-07-29
- 状态：已实现，待 Claude 独立审计
- 决策：`@wenshu/editor-transactions` 成为人工与 AI 编辑的唯一权威写边界。

## 决策

1. 事务固定为 `begin → apply* → validate → commit | rollback`。PB-02 操作只改变
   session 的私有暂存 ProseMirror 文档；manager 的 snapshot 仅在 commit 后替换。
   apply 失败、提交校验失败和取消都返回 `rolled_back`，不暴露部分文档。
2. `TransactionManager` 独占可见文档、undo/redo 栈与 active session。session 的
   finalize 需要未导出的 capability；外部不能自行把暂存文档提交为 manager 状态。
3. 提交前反向通过 PB-02 adapter / G1-04 `validateDocument`，并逐一确认除显式
   delete subtree 外的既有 ID 均保留。PB-02 的 schema/ID 守卫是唯一校验来源。
4. cancel 既可由 `AbortSignal` 在异步执行中触发，也可由 manager 直接调用；二者
   只回滚暂存状态，终态后重复 cancel 返回同一结果。
5. public `@wenshu/semantic-editor` 不再导出 raw 操作；它们只作为
   `@wenshu/semantic-editor/internal` 供事务包使用。没有 UI、持久化或 AI 工具可
   以此为应用写入口。

## 后果

- undo 保存已提交事务的 before/after 文档，redo 复用同一 after；两者不会重新
  分配 ID，且 redo 后必须与提交后 deep-equal。
- 事务只保留操作与受影响节点 ID，不写语义审计、出处、存储或按键日志；这些职责
  留给 PB-04、PB-05、PB-06、PB-08。
- 本任务未新增第三方运行时依赖；SBOM 仍为 170 包。
