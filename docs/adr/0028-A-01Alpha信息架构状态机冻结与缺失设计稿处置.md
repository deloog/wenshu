## 2. D2：「可验收原型」形态——L0 契约 + 最小可运行原型

业主 2026-08-01 裁定采纳推荐项：

1. **状态机做成版本化契约包 `@wenshu/ux-state`（L0）**：JSON Schema（
   `stateVersion` const `1.0.0`，reader fail-closed）+ Ajv 校验 + 语义层
   （重复 id/悬空转移/按 id 条件扩展）+ 生成物漂移检查接入
   `pnpm verify`。理由：本棒消费者 12 个（A-02/02D/03/04/04T/05/06/07/08/
   09/10P/10X），散文描述必然分叉；G1-04/G1-06/G2-04 已证明「契约先行 +
   门禁机械校验」能防住这类分叉。
2. **apps/web 最小可运行原型**：12 状态逐行画廊 + IA 八区骨架。
   `requiredPresentation`/`forbiddenSemantics` 从契约**逐字**进入
   view-model，缺一条测试即红。原型是验收工装：**不是设计系统、不是组件
   库、无样式体系**（路线图范围外原文「不做完整设计系统」）。

**12 行枚举边界的双来源（业主 2026-08-01 书面更正，防加严/放宽含糊）**：
12 行逐行有原型。其中 7 行（导入中/导入部分成功/AI 处理中/分页中/离线/
权限拒绝/崩溃恢复）直接对应路线图 §7 A-01 完成证据 6 类（加载/部分成功/
失败/取消/离线/恢复）；4 行（初次/空项目、AI 结果、页面有问题、导出前）
的强制性来自 ux-spec §4 表头「必须呈现」；保存成功/失败行为 dual（失败侧
归路线图，成功侧归 ux-spec §4）。两条来源在契约 `evidenceSource` 字段与
[冻结文档](../alpha-ux-freeze.md) 对账表中分别写明。

**已知代价（如实登记）**：原型经 `UX_STATES` 模块级自校验引入 Ajv，web
bundle 145 kB。验收工装可接受；A-02 真实 UI 若需瘦身，可拆纯数据入口，
另行评估。

## 3. D3：与 DEGRADE 的接口——状态机按增量分页建模

PoC-A 结论是 **DEGRADE**（决策 #11A），全量分页 not_met（PA-13 实测
p95 24.3 s / 预算 8 s）；ADR-0014 把增量分页登记为 PB/Alpha 待建架构要求。
本契约在**模式层面**钉死：

- `pagination` 状态扩展：`repaginationScope: const "incremental"`、
  `stalePreviewRetained: const true`、`cancelable: const true`、
  `updatedPageRange`（部分页已更新、旧预览仍有效的表达位）；
- `fullRepagination` 字段**契约级禁止**（property schema `false` +
  `additionalProperties: false` 双闸，变异测试与 schema 防回归守卫钉死）；
- A-01 **不实现分页**——冻结的状态定义为 A-04 留出增量位置，如此而已。

## 4. D4：G2-03 MI-03 关闭——包根配置文件归 auxiliary 规则集

**裁定**：`<workspace>/*.config.{ts,mts,cts}`（包根）与 `hvigorfile.ts`
（任意深度）归入 **auxiliary 规则集**（与 test/scripts 同级：允许

**反例**（`tools/quality/test/layering.integration.test.ts`）：

`@ohos.web.webview` → `ARKTS_FORBIDDEN`。正面：`node:*` 放行、文件计入
`auxiliaryFiles`（全仓 unclassified 14 → 11）。

## 5. D5：apps/web 全局类型洞收口——eslint 禁 Node 全局，不拆 tsconfig

**问题**：`apps/web/tsconfig.json` 声明 `types: ["node"]`，`process`/
`Buffer` 无需 import 即可 typecheck，分层门禁只看 import 看不见。

**裁定**：不拆 tsconfig（仓内无拆分先例，且 typecheck-coverage 门禁钉死
`tsc -p tsconfig.json` 逐字与全覆盖）；改在 `eslint.config.mjs` 对
`apps/web/src/**` 禁 `process/Buffer/__dirname/__filename/global`
（`no-restricted-globals`）+ `globalThis.process/globalThis.Buffer` 绕过
（`no-restricted-syntax`）。双闸互补：分层门禁管 import，eslint 管全局。
反例已验证决定性（两种注入均 lint 红）。

**残余（如实登记）**：该闸是文本闸非类型闸——类型层面 `process` 仍可被
typecheck 接受（不使用即不报错）；`globalThis["pro" + "cess"]` 类动态拼
接不在静态分析范围。拆 `tsconfig.src.json`/`tsconfig.node.json` 留作后续
选项。

## 8. 实施期实测发现（如实登记）

1. **json-schema-to-typescript 不支持 `allOf`+`if/then`**：初版 schema 用
   if/then 按状态 id 强制扩展字段，生成物退化为 `{ [k: string]: unknown }`
   ——12 个消费者将失去类型。改为代码语义层强制
   （`UX_STATE_EXTENSION_MISSING`），schema 描述中书面记录原因。
2. **Ajv strict 拒绝「未定义属性的 required」**：`not: { required: [...] }`
   引用未声明属性触发 `strictRequired` 错误；改为属性 schema `false`
   （JSON Schema 2020-12 合法布尔 schema），语义等价且更显式。
3. **测试夹具取舍**：schema `minItems/maxItems: 12` 使独立 invalid 夹具文件
   成为纯重复；改为测试内从冻结定义确定性派生变异（单源），不设
   fixtures/ 目录。
