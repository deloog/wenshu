# ADR-0008：PA-09 表格跨页检查严重级证成与 DOM 对账归属

- 日期：2026-07-26
- 状态：已接受（实施决策，随 PA-09 独立审计复核）
- 关联：路线图 PA-09 行（「真实 PDF + DOM 对账；表格 fault 全覆盖」）、ADR-0007（P1 严重级与诚实降级先例）、ADR-0006（证据契约 v1.1.0 成员标记）、PA-09 开工指令

## 背景

PA-09 要求实现表格跨页、表头重复与行切断检查，消费 PA-06 v1.1.0 证据
（纯几何 run，无表结构）与文档期望块（含表结构），模板阈值来自冻结模板
`table_repeat_header` / `table_row_break_inside`。两个先决问题需要书面化：

1. **严重级**：两个新检出码为什么定 P1 而不是 P0。
2. **归属方法**：证据里没有任何表结构标记，行/列/单元格身份只能从
   文档侧文本对账重建——这正是路线图写「DOM 对账」的原因；对账失败时
   怎么处理直接决定诚实门成色。

实施期签署基线探针实测（留痕于实施记录）得到决定性事实：

- 基线 5 张表，唯一跨页表为「主要风险与首期处置」（7 行 × 4 列，
  pageIndex 11→12）；Chromium 按 PA-04 CSS（`thead` header-group +
  `tr break-inside: avoid`）**真实重复了表头**（p12 页首 15 个表头 run
  位于首个数据行基线之上）且**整行未切断**。路线图停止条件（「表格无法
  通用分页则触发 PoC-A 风险评审」）因此判定不触发。
- 基线 run 多为单字 run；短单元格文本（如「风险」）会撞上章节标题
  「六、风险、边界与降级」的内部子串；同文单元格真实存在（同列多行
  同值）；单元格内换行、列宽不均真实存在。

## 决策

1. **严重级证成：两码均 P1**。续页表头缺失与行切断是排版质量缺陷——
   内容仍在证据中（文本 run 全部存在，非内容丢失，故非
   `P0_CONTENT_MISSING`），未越出版心、未遮挡（故非 PA-07 P0 域），
   违反的是冻结模板声明的分页规则。与 ADR-0007 的 P1 警告级口径一致：
   模板规则违反但不构成内容丢失/遮挡/越界。
2. **DOM 对账归属三重防线**（任一不过即歧义，歧义 fail-closed）：
   - run 边界对齐：单元格文本必须是整 run 序列拼接，拒绝嵌入更长
     文本内部的子串误配（防「风险」撞标题内部子串）；
   - 反向文档序游标：同文重复时取阅读序上紧邻表格数据的较晚出现
     （thead 在 DOM/阅读序中先于 tbody，同文单元格按反向文档序解析）；
   - 几何一致性：同单元格同页单 MCID 块序（跨块=归属疑嵌入）、
     列带（该列全部格 x 并集）相邻不重叠。
   歧义表整表降级 `P1_TABLE_STRUCTURE_REVIEW` 人工核验项（复用
   ADR-0007 manualChecks 通道），两条判定规则均跳过该表——不猜、不藏。
   行内列 x 序不单列校验：列带相邻不重叠逻辑蕴含任意行内列 x 序成立
   （证明见实施记录），实施期变异测试证实该冗余后删除。
3. **判定口径**：
   - `P1_TABLE_HEADER_NOT_REPEATED`：`table_repeat_header: true` 时跨页
     表的每个续页，表头文本须在该页**首个数据行基线之上**的对应列带内
     出现；缺失即报，定位页 + 表根 ref，metrics 带应/实表头数与模板值。
     表头出现在首个数据行之下不计数（防把同文数据单元格误认为表头）。
   - `P1_TABLE_ROW_SPLIT`：`table_row_break_inside: "avoid"` 时同一
     `/rows/<r>` 的单元格 run 不得分处页界两侧；违反即报，定位页 +
     表/行 ref。整行同页的跨页（行界分裂）合法不报。
   - 模板对应键为 `false`/非 `"avoid"` 时规则空转（模板未承诺即不判）。
4. **无合并单元格**：路线图已圈定范围外；合并单元格导致的归属歧义
   由防线 3 几何校验 fail-closed 兜住（降人工核验），不做几何启发式猜测
   ——与 PA-06B 成员标记「解析期事实禁几何启发式」同一纪律。

## 后果

- 签署基线在表格规则下 0 自动发现、0 新增人工核验项（PA-08 钉数 30
  不回潮），作为审计可重放基线。
- PA-12 汇总门禁的表格 fault 检出域由此两条规则承接（P0+P1 ≥10/12
  口径中占 2 类 fault）；`P1_TABLE_STRUCTURE_REVIEW` 人工项并入
  PA-12/PA-14U 人工清单（PA-J1 口径）。
- 已知边界：归属依赖单元格文本在证据中可匹配——表格文本缺失属 P0 域
  （attribution 跳过），不在本规则重复报告；复杂嵌套表/跨列表触发的
  是 fail-closed 人工核验而非误报。
