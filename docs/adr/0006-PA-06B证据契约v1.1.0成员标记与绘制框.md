# ADR-0006：PA-06B 证据契约 v1.1.0——figure 成员标记与绘制框（paintBBox）

- 日期：2026-07-25
- 状态：已接受（实施决策，随 PA-06B 独立审计复核）
- 关联：决策 #10（PA-I1 裁定选项 B）、PA-07-followups.md PA-I1、ADR-0005

## 背景

决策 #10 裁定：PA-07 遮挡豁免从几何包含制收紧为**成员制**——只豁免 figure
自有内容的文本 run，成员判定 = 解析期结构事实（禁几何启发式）；证据契约
additive 升级 v1.0.0→v1.1.0；使「图遮正文（含完全覆盖、不骑缝）」检出为
P0_OVERLAP，且签署基线仍 0 P0。

实施期实证（探针留痕于 PA-06B 实施记录）发现一条开工指令未覆盖的形态约束，
它决定了契约必须新增**两个**而非一个事实：

1. 签署基线两个 figure 的 `bbox` 都是**版心全域**（51, 784.92, 493.23×728.52）
   ——撑大来源是 span 内一个版心大小的 `re W* n` **clip 矩形**（自家管线 SVG
   根背景只裁剪、不绘制）；figure 页全部正文 run（p7 506、p9 570）几何上都
   完全落入 figure bbox。
2. 因此「非成员 run 与 figure **bbox** 显著重叠 → P0」在基线上会产生约
   1076 条误报，与「基线仍 0 P0」不可兼得；绘制顺序（paint order）同样不能
   区分（p9 figure span 之前已有正文块，但它们在图表区之外）。
3. 唯一能同时满足漏检门与误报门的语义：遮挡判定针对 figure 的**绘制范围**
   （painted extent）——clip 不绘制（PDF 语义），遮住正文的只可能是绘制内容。

## 决策

1. **`TextRun.figureMcid: number | null`**（v1.1.0 必需）：run 的全部字形都
   在同一个 /Figure BDC…EMC span 内发出时为该 span 的 MCID，否则 null；
   跨 span 边界的混合 run 判 null（骑缝 ≡ 非成员，与旧「骑缝即 P0」一致）。
   判定唯一事实源是发出时刻的标记内容栈，禁任何 bbox 几何推断（决策 #10
   命门）；几何启发式回退由决定性源码变异测试锁死（变异即红）。
2. **`FigureBox.paintBBox: BBox`**（v1.1.0 必需）：仅绘制算子（f/F/S/s/B/b
   家族）消费的路径点 + 成员文本 run 包围盒的并集；clip（W n）不计入。
   既有 `bbox` 语义不变（含 clip，ADR-0005 oracle 交叉口径不动），
   paintBBox ⊆ bbox 作为提取不变量进契约语义校验。
3. **p0-overlap 判据**：figure 侧几何改用 paintBBox；配对豁免当且仅当
   run.figureMcid 与 figure MCID 相同（同图自有内容互叠含标签-图、标签-
   标签）；非成员 run 与 paintBBox 任何显著重叠（含完全包含、不骑缝）→
   P0_OVERLAP；同行字距豁免等其余边界不动。
4. **契约纪律**：v1.0.0 schema 原样冻结保留（`evidence-1.0.0.schema.json`，
   仅 title 因生成命名调整为 `WenshuPdfEvidenceV1_0_0`），reader 双版本分发
   （1.0.0/1.1.0 各自 schema 校验 + 共享语义校验，1.1.0 增成员引用完整性与
   paint⊆bbox 校验）；生产器只产 1.1.0；report-checks 作为当前唯一消费者在
   runner 入口对旧版证据 fail-closed（`REPORT_CHECKS_UNSUPPORTED_EVIDENCE`）。
5. **oracle 同步**：pdf.js constructPath 的 args[0] 区分绘制（fill/stroke
   家族）与非绘制（endPath/clip），oracle 交叉验证增加 paintBBox 四边 ≤2pt
   比对——新事实同样获得独立第二真源（实测 0 不一致）。

## 消费者重审记录（契约升版纪律）

- **report-checks（当前唯一消费者）**：随 PA-06B 同步升级——P0CheckInput
  类型升 1.1.0；p0-overlap 按上文 3 重写豁免；runner 增版本 fail-closed；
  基线集成测试钉定成员事实（p7 成员 58 / p9 成员 80、非成员与 paintBBox
  零显著重叠）+「图遮正文不骑缝」fault 检出 + 成员豁免不误报。
- **PA-08~12（未来消费者）形状约束**：证据对象为 1.1.0；需要成员语义的检查
  必须使用 figureMcid（结构事实），不得自行做 bbox 包含推断；figure 的
  「可见范围」语义用 paintBBox，bbox 仅用于版面边界类判定（如 p0-bounds）。

## 结果

- 基线实测：p7 figure paintBBox (87.01, 784.92, 421.48×238.84)，p9 (87.00,
  553.92, 421.50×182.65)；成员 58/80 run；非成员与 paintBBox 显著重叠 0 处
  ——误报门成立；合成/派生 fault「图完全覆盖正文不骑缝」→ P0_OVERLAP 检出
  ——漏检门关闭。
- PA-I1 暴露面（几何包含豁免在 figure 页事实上关闭整页遮挡检查）随成员制 +
  绘制框一并关闭。
- 证据契约进入 v1.1.0；v1.0.0 数据在 reader 下保持合法（fixture 钉定）。
