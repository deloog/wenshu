# 文枢性能预算（G0）

> 状态：G0 已批准（2026-07-20）；G1 建立“参考机器”说明和自动采样方法后成为 CI 阈值。所有数字针对首战上限样本（30,000 字、30 页、普通表格与压缩后图片），不代表无限大文档。

## 参考任务预算

| 指标 | 目标 | 失败处理 |
|---|---:|---|
| 启动到可操作（热启动） | ≤ 2 秒 | 超过即分析主线程、I/O 和包体 |
| 打开本地首战上限项目 | ≤ 3 秒 | 提供渐进加载，不能冻结无反馈 |
| 普通键入/选择响应 p95 | ≤ 100ms | 长任务必须移出主线程或分片 |
| 局部编辑后相关页面更新 | ≤ 1 秒 | 允许显示“正在重新分页”，旧预览不消失 |
| 30 页完整重新分页 | ≤ 8 秒 | 可取消；超时产出诊断 |
| 30 页 PDF 导出 | ≤ 30 秒 | 可取消；不得阻塞编辑器和丢失项目 |
| 页面检查（30 页） | ≤ 5 秒 | 按严重度渐进显示结果 |
| 崩溃后恢复到可操作 | ≤ 10 秒 | 明确恢复点和可能丢失范围 |
| 首战上限项目峰值内存 | 软目标 ≤ 1GB | 超过需记录原因；持续增长视为泄漏 |

## 稳定性预算

- 同一输入、同一环境重复 10 次，页数和阻断 validator 结果必须一致。
- 关键操作不得出现未响应超过 2 秒且没有进度/取消反馈。
- 导出失败不得损坏项目或上一次成功成品。
- 批量 AI/分页任务都有超时、取消和资源清理；取消后 2 秒内停止继续消耗主要计算资源为目标。

## 输入护栏

- 首战官方支持上限为 5,000–30,000 字、10–30 页。
- 单附件、图片数量/尺寸、表格行列和解压后总量的具体上限在 G1 用 fixture 实测后锁定。
- 超出上限时先预检并提示，而不是开始处理后卡死；允许用户选择压缩、拆分或继续承担风险。

## 回归规则

- 基线记录运行时、OS、CPU、内存、磁盘、字体和 fixture 哈希。
- 单次噪声不直接判失败；使用多次运行的中位数/p95，并保存原始数据。
- 关键指标相对已批准基线退化超过 20% 时阻断合并，除非有记录的质量收益和批准。
- 性能优化不能降低 PDF 正确性、数据安全、可访问性或测试真实性。
