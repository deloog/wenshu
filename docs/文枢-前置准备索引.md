## 适用性画像

| 问题 | 结论 | 依据/影响 |
|---|---|---|
| 有用户界面 | 是 | Web 试用入口、Windows/macOS 桌面生产环境、后续鸿蒙及移动端 |
| 有服务端 | 后期可能 | Alpha 本地优先；同步与可选云服务后置，不能提前制造服务端负债 |
| 有数据库/索引 | 是 | 本地项目存储候选 SQLite；向量索引属于可重建派生数据 |
| 读写本地文件和用户资料 | 是，高风险 | 涉及文件权限、数据主权、导入/导出、备份恢复和路径安全 |
| 调用 AI/非确定性系统 | 是 | BYOK、多模型、端云混合；必须 schema 校验、权限控制、评测和降级 |
| 调用付费或限额第三方 | 是 | 模型 API 及后续可选服务；必须预算、限流、熔断和用户确认 |
| 处理个人/敏感数据 | 可能 | 用户资料、历史项目、引用来源可能含敏感内容；默认本地、最少外传 |
| 账号/权限/支付/多租户 | 分阶段 | Alpha 不以账号为前提；商业化与同步阶段另开闸门 |
| 多平台/多语言/无障碍 | 是 | Chromium/Electron/ArkWeb；中文排版优先，同时覆盖中英文混排 |
| 对外发布/上架/自动更新 | 是，后期 | Web、桌面、鸿蒙依次发布；均须通过 G3 |
| 不可逆或高成本操作 | 是 | 文件覆盖、项目删除、迁移、正式导出、模型调用等需分级保护 |
