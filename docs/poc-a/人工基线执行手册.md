# PoC-A 人工基线执行手册

> 版本：1.1　日期：2026-07-20　状态：已完成右删失试跑，不再重跑  
> 本手册只把《PoC-A 实验说明》中已经冻结的 WPS/Word 对照要求转成可执行步骤，不改变样本、合格标准或通过门槛。

## 1. 为什么必须由 0 号用户亲自执行

人工基线测量的是非技术用户从固定 AI 草稿到“愿意实际发送的 PDF”所需的真实时间。AI 可以准备软件、样本、计时表和检查表，但不得替 0 号用户操作排版，也不得用脚本或自动化模拟人工时间；否则基线失去比较意义。

## 2. 每个工具使用完全相同的输入

- 主文稿：`docs/poc-a/fixtures/golden-report.md`，版本 `1.0.0`。
- 图片：`chart-overview.svg`、`chart-process.svg`。
- 数据：`report-data.csv`，仅用于核对表格和图片，不重新生成或替换内容。
- 目标规则：`formal-business.template.json` 版本 `1.0.0` 与《PoC-A 实验说明》的“最小模板规则”“PDF 合格标准”。
- 记录表：`manual-baseline.csv`。

不得先把另一工具已经排好的 DOCX、模板、样式库或 PDF 复制到当前工具。允许使用当前工具自带的普通样式、目录、页眉页脚、表格和导出功能，但所有设置都应在本次计时内完成。

## 3. 测试前准备（不计时）

1. 关闭无关程序，暂停会明显占用网络、CPU 或磁盘的任务。
2. 记录操作系统、软件完整版本、系统缩放和显示分辨率。
3. 为本次测试新建独立输出目录，例如 `D:\wenshu\artifacts\manual-baseline\WPS-BASE-01`。
4. 打开本手册、固定主文稿、两张图和计时工具，但不要提前创建样式或编辑文稿。
5. 确认源文件没有被修改；若误改，应从冻结样本重新开始。

## 4. 计时边界

### 总时间

- **开始：** 0 号用户开始把 `golden-report.md` 内容送入一个全新的空白文档时。
- **结束：** 第一份满足检查表、且 0 号用户愿意真实发送的 PDF 已成功导出并能重新打开时。
- 中途查帮助、试错、撤销、等待导出、返工和最终检查均计入总时间。
- 非人为中断（停电、系统更新、紧急离开）应暂停并在备注中说明；普通休息和犹豫不暂停。

### 纯手工排版时间

用单独秒表累计以下操作：标题/正文样式、字体字号、段落间距、分页、目录、页眉页脚、表格、图片、题注、来源、页码及为修复页面问题而做的调整。内容复制、事实核对和最终通读不计入纯排版时间，但仍计入总时间。

### 人工格式调整次数

一次有明确目的、可以撤销的格式动作记为一次，例如“把一级标题应用统一样式”“调整一张图的宽度”“修复一个标题落页尾”。连续输入同一设置值算一次；为同一问题反复尝试不同值，每次尝试分别计数。无需精确到每一次鼠标点击。

## 5. 执行步骤

1. 启动总计时和排版计时记录。
2. 将固定 Markdown 内容完整送入空白文档，保留所有文字、表格、列表、链接和占位标记。
3. 按固定规则建立封面、独立目录、正文层级、页眉页脚和页码。
4. 在对应位置插入两张固定图，设置题注与来源；不得替换图片或删减文字来迁就页数。
5. 处理表格、长链接、中英文混排、附录和跨页关系。
6. 更新目录并导出 PDF。
7. 在至少两个独立 PDF 阅读器中打开；逐页执行第 6 节检查。
8. 若不合格，返回源文档修复、重新更新目录并导出；所有返工继续计时。
9. 当第一份 PDF 通过且愿意发送时停止总计时，立即填写 CSV。

## 6. 停表前检查

### P0：任何一项存在都不得停表

- 页面或内容丢失、重复、截断，或 PDF 无法打开、搜索、复制正文。
- 正文、表格、图片越界或互相遮挡。
- 目录页码错误、关键页空白或明显字体缺失。
- 内容与冻结样本不一致，或为适应排版删改了事实、数字和段落。

### P1：原则上修复后才能停表

- 标题落在页尾，或标题与至少两行正文分离。
- 表格表头跨页后未重复，表格行被不合理切断。
- 图片与题注分离，题注与来源分离。
- 明显孤行、寡行或无法解释的大面积空白。

如确有无法修复且 0 号用户仍愿接受的 P1，必须在 `unresolved_p1` 和 `notes` 中写明数量、页码、现象及接受原因；P0 不允许人工豁免。

## 7. 记录与证据

每次运行至少保留：源文档、首次可接受 PDF、软件版本截图、计时结果、填写后的 CSV，以及可选的屏幕录制。文件名应含运行编号和工具，例如 `BASE-01-WPS.pdf`。

`manual-baseline.csv` 字段填写口径：

- `total_minutes`、`manual_formatting_minutes`：保留一位小数。
- `manual_adjustments`：按第 4 节口径记录整数。
- `unresolved_p0`、`unresolved_p1`：停表时尚存在的问题数量。
- `would_send`：只能填 `yes` 或 `no`；只有 `yes` 才构成有效人工基线。
- `notes`：写明异常、暂停、未解决 P1、字体替代、软件许可或环境限制。

## 8. 顺序与学习效应

如果 WPS 和 Word 均可用，首次执行顺序由简单随机方式决定（例如抛硬币），第二个工具至少间隔一天执行；不得在间隔期间专门练习该样本。若未来复测，交换工具顺序。两次运行都从冻结源文件开始。

## 9. Word 延期决定

业主已于 2026-07-20 批准本机不安装 Word，Word 基线延期为后续兼容性补充项，不再阻断 G0。不得用 WPS 数据冒充 Word，也不得删除 `BASE-02`；记录表必须保留延期原因。若后续真实用户明显依赖 Word，应在已有合法授权环境补做兼容性抽查。

## 10. G0 关闭条件

业主于 2026-07-20 批准 `BASE-01` 以 122.3 分钟、`would_send=no` 的右删失观察作为 G0 人工下限证据，不再要求继续或重跑；Word 延期决定已经完成。该例外只改变 PoC-A 的个人工程门槛，不降低固定长文和 PDF 合格标准，也不替代阶段 2 的完整用户对照。
