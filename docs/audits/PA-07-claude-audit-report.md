## 4. 观察项 · PA-I1（figure 包含豁免 → PA-07/PA-10 边界，需裁定）

- **证据（我合成确证）**：`p0-overlap` 对**完全落在某 figure bbox 内**（±0.5pt）的文本 run 整体豁免（`filter(run=>!contained(run))`）。合成测试：figure 完全包含一个孤立正文 run → **P0_OVERLAP=0（豁免,不报）**;对照同位置用大 text run 覆盖 → 全检出。
- **定性**：豁免是**书面化+校准**的（figure=SVG 根背景,图表标签/题注落在图内是其自有内容,否则满图标签全成误报）;现实中 figure 遮正文会**骑缝**（部分重叠）→ 已检出（`report(run, figure)` 对未包含 run 生效,我实测满版 figure 仍报骑缝 P0）。
- **风险**：一个**完全覆盖正文且不骑缝任何邻居**的 figure（图片遮正文的极端形态）不会被 `p0-overlap` 报 P0——这落在"P0 漏检"这一 FAIL 类别的边缘。
- **裁定诉求（非阻断,但须在 PA-12 前钉死）**：图片遮正文的遮挡归 **PA-07 还是 PA-10（图片越界/遮挡）**?请业主/下游明确边界,并确保 PA-12 的 12 个 fault 样本集覆盖"图遮正文",**别让它在 PA-07 与 PA-10 之间两边都漏**。若定为 PA-10 域,PA-07 现状可接受;若定为 PA-07,则需收紧 figure 包含豁免（如仅豁免 figure 自身内容流的 MCID 标签,而非任何几何落入者）。
