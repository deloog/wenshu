# PA-01 固定 Markdown 解析为 v0 类型化文档实施记录

> 日期：2026-07-23　状态：已实现，待独立审计；本记录不关闭 PA-01。前置：G1-04/08/10/16、G2-01/02、PA-00 全部签署。

## 实施范围

- 新包 `@wenshu/markdown-import`（**零新增第三方依赖**）：行式严格子集解析器 + 文档装配 + 全文逐字对账。
- 支持面（严格等于 fixture 构造）：YAML front matter 平铺条目、#/##/### 标题、段落、单级引用、有序/无序列表（单级）、GFM 表格（含对齐行）、图片（本地相对路径）、`[[PAGE_BREAK]]`→pageBreak 块、`[[TOC]]`→识别消费不落块。范围外语法（代码围栏、四级标题、HTML、缩进块、Setext、行内链接、转义管道、未知标记）一律 fail-closed。
- 内容对账：每个源字符归账为"文档内容"或"已记录语法消费"（含 `**`/`*`/反引号行内标记、front matter 非 title 元数据、表格管道、块内合并换行），恒等式 `内容 + 语法 + 换行 = 源长度` 逐行可验；产出文档经 v0.1.0 schema 与完整性校验通过。
- 稳定 ID：`node_/item_/col_/row_/cell_/asset_` + sha256(序号:类型:内容) 前 32 位，重解析逐字节幂等，重复内容不撞 ID。
- 资产：按 PA-00 裁定内容寻址重命名（`assets/<sha256前16>.<小写扩展名>`）、白名单媒体类型、远程引用/越根路径 fail-closed、SHA-256 实算。

## 关键设计取舍（实施者裁定，供审计重放）

1. **范围词"标记"的读法**：范围列举"标题、段落、列表、引用、普通表格、图片、标记"——前六项与 v0 块类型一一对应，且 fixture 确有 `[[PAGE_BREAK]]`/`[[TOC]]` 自定义标记，故"标记"=自定义标记，粗体不在范围内。
2. **行内强调剥离**：v0.1.0 无行内强调结构（schema 对 strong/emphasis 零定义，冻结模板亦无强调样式槽）。fixture 全部 10 处粗体均为行首标签式（标签-值结构，无句中强调），剥离 `**` 后文字连冒号完整保留——内容零丢失，仅失字重。**标签字重的表现责任显式交棒给 PA-04 模板解释器**（模板已声明 400/500/700 三档字重），不让其静默消失；若 PA-04 判定模板需"标签"样式槽，届时按其自身契约流程处理。
3. **`[[TOC]]` 消费不落块**：目录是 PA-11 的生成物职责，不是源内容；不冲突。
4. **schema 未触发"无法无损表达即停修"**：内容无损（文字零丢失），强调属表现层已有承担方，故未改 Schema。
5. **front matter 非 title 元数据**（author、fixture_id 等）：v0.1.0 文档对象无对应字段，按"元数据消费"计入语法，不进文档；留痕通道（PA-00 的导入报告）属后续导入管线职责。
