# PA-01 固定 Markdown 解析为 v0 类型化文档独立审计任务书（交给 Claude）

> 日期：2026-07-23　实施基线：PA-01 PR 合并提交（见 gh pr 记录）　报告目标：`docs/audits/PA-01-claude-audit-report.md`

## 1. 角色与写入边界

你是独立只读审计者。不要采信实施记录、对账输出或测试全绿自述；独立重放解析、重算对账、审查取舍。

- 只允许新增/修改上述审计报告；不得修改代码、测试、Schema、fixture、文档或配置。
- 仓库外探针只写 `D:\tmp\pa01*`，结束后删除；不得 push、创建 PR 或触发 Actions。

## 2. 内容对账（核心）

- 用独立脚本对 golden-report.md 重算：全文逐字归账（内容 + 语法 + 换行 = 源长度）是否对任意行成立，而非仅汇总成立；抽查含 `**`、反引号、表格、图片、front matter 的具体行。
- 验证"内容零丢失"：文档全部文本节点的字符与源内容字符一一对应（顺序、次数），`**`/`*`/反引号计入语法消费而非静默丢弃；`[[TOC]]` 消费不落块且与 PA-11 职责不冲突。
- 表格：列头/对齐/每个单元格文本与源一致；图片：两个 asset 的 SHA-256 与冻结 SVG 实算一致、内容寻址重命名符合 PA-00 §7.2。
- 稳定 ID：重解析幂等；构造重复内容段落确认 ID 不撞；改造输入确认 ID 变。

## 3. 取舍审查

- "标记"读法（自定义标记 vs 强调标记）：对照范围列举与块类型映射独立判断；若认定粗体属范围内缺项，指出。
- 行内强调剥离：核实 fixture 粗体全为行首标签式（句中强调为零）；"内容 vs 表现"边界与"字重表现交棒 PA-04"的责任链是否成立、是否掩盖 PA-15 交付观感风险。
- front matter 非 title 元数据按语法消费：与 v0.1.0 文档对象字段一致，无静默丢弃应入文档的信息。

## 4. 边界与门禁

- 范围外语法 fail-closed 逐类实测（代码围栏、四级标题、HTML、缩进块、Setext、行内链接、未知标记、远程/越根引用、残缺表格）；错误分类稳定、不回显正文。
- 零新增第三方依赖（SBOM 147 包无新增、phantom 守卫通过）；`contracts:test` 接线真实承重（删掉本包应被发现）。
- 守卫决定性：变异关键守卫（行内剥离、对账恒等、schema 校验、ID 序号）测试应变红。
- `pnpm --filter @wenshu/markdown-import test`、`pnpm contracts:check`、`pnpm verify` 复核；冻结 fixture/字体/Schema/生成物零漂移。

## 5. 结论规则

- 任一源字符无归属或重复计入、内容/表格/图片引用丢失、schema 未通过却声称通过、范围外语法可混入、"标记"读法不成立致范围缺项、新增未申报依赖：`FAIL — PA-01 不得完成，PA-02/03 不得启动`。
- 无 BLOCKER/MAJOR 且 MINOR 有归属：可给 `CONDITIONAL PASS`；完全满足给 `PASS`。审计者只给结论，由 Codex 完成台账。
