# G1-10 fixture 完整性与隔离复制实施记录

> 日期：2026-07-20　状态：已实现，待独立审计；本记录不关闭 G1-10。

## 实施范围

- 为 7 个既有 PoC-A 原件新增严格 `manifest.json`，登记字节数和 SHA-256；原件字节未改动。
- 新增 `@wenshu/fixtures`：严格解析、动态枚举、manifest 自身哈希锚定、源/副本双重校验和隔离证据生成。
- 复制只接受运行时签发的 `PreparedTestIsolation`，目标固定在 worker 的 `files/`，排他创建且不记录绝对路径。
- 新增契约测试和真实文件系统集成测试；`fixtures:check` 接入完整 `verify` 与 CI `contracts` 作业，不新增远程矩阵项。
- 未实现 PDF、渲染、模板解释器或产品功能；没有数据库、外部账号、费用和新第三方依赖。

## 已执行反例

- 对 7 个冻结文件逐个改变首字节：7/7 返回 `FIXTURE_SET_MISMATCH`。
- manifest 替换为 `{}`、删除登记文件、增加未登记文件：全部拒绝。
- 在冻结目录副本植入真实 Windows junction：拒绝且不读取链接外文件。
- 冻结结构复制的隔离句柄：运行时所有权校验拒绝。
- 同一 worker 第二次复制：因排他目录已存在而拒绝，不覆盖首份证据。
- 合法复制逐文件对比原件/副本字节和 SHA-256，证据文本不含源目录或受控根绝对路径。
