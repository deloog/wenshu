## 4. oracle 压印排除口径正当性（独立核）

- **排除口径确定性、非几何**:`stamp-scope.ts` 以 `^STAMP_FONT_TAG_PREFIX\d+$`(pdf-export 单源常量,压印字体 PA11F1/F2/F8)过滤,**禁位置/字号几何启发式**;引擎字体为 F4..F256,无 tag 碰撞;排除窄(仅压印层)。
