## 原始反例

首审证明：跟踪文件只要包含一个 NUL 字节，扫描器就静默跳过内容，却仍输出该文件已计入 `Secret scan passed: N tracked files`。当前仓库没有含 NUL 文件或已发生的密钥泄露，但该门禁可被单字节击穿。

## 测试先行与修复

先新增一个由“合法形态 AWS access key + NUL”组成的临时跟踪文件测试。修复前 `@wenshu/ci` 为 6/7，通过项不变，新增用例因实际返回空 findings 而失败。

修复删除了 NUL 静默跳过分支。所有普通跟踪文件现在都读取并进行 UTF-8 容错解码；高置信度 ASCII 模式在 NUL 前后仍可命中。符号链接、禁止文件名和读取失败继续 fail-closed。成功输出中的 tracked file 数不再包含“因 NUL 未内容扫描”的文件，因为此类跳过已不存在。
